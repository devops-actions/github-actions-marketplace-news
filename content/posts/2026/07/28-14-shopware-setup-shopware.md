## Action Summary

This GitHub Action automates the setup of Shopware, PHP, MySQL, and Node.js environments for unit testing and end-to-end testing in GitHub Actions workflows. It simplifies the process by installing Shopware from a specified repository and version, setting up PHP with optional extensions and ini values, configuring MySQL, and optionally building Shopware's Administration and Storefront assets. The action supports customizing the installation with locale, currency, and bundle disabling options, and keeps Composer tools after installation.
