## Action Summary

The PHP Matrix Action generates a version matrix based on the PHP constraint in your `composer.json`. It automates tasks related to managing PHP versions, ensuring compatibility with dependencies and avoiding issues caused by outdated or incompatible versions. The action supports two modes: minor-only and full, allowing users to select which versions are reported. It also includes options for specifying the source of release information and verifying attestation.
