## Action Summary

The Profile Cards Action generates SVG profile README cards using the GitHub GraphQL API. It automates the rendering of stats such as lifetime and current-year contributions, stars, followers, merged PRs, issues, public repositories, recently contributed-to repositories, contribution history, streaks, contribution composition, activity rhythm, and a language treemap. The action writes these SVG files into the repository, providing self-hosted, reproducible, and theme-aware profiles.
