## Action Summary

Holt is a GitHub Action designed to help manage multiple worktrees created by different agents. It checks which worktrees contain uncommitted changes that do not exist in committed work, and prevents deletion of these worktrees that might have conflicting or duplicate content. The action uses Git's own worktree lock mechanism to ensure safety during deletions.
