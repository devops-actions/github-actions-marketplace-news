## Action Summary

This GitHub Action collects Cargo/Rust project metadata and provides outputs for packages, features, publishable packages, and a job matrix. It helps automate tasks such as publishing crates, running tests per-package, and building per-feature by exposing parsed lists extracted from `cargo metadata`.
