## Action Summary

This GitHub Action automates the local-first visual regression testing of web applications. It captures screenshots, compares them with snapshots of the page's DOM, and generates an HTML report highlighting changes and areas of noise. The tool is designed to be fully self-contained and uses DOM-aware techniques to minimize false positives. Users can integrate it into their CI workflows to detect and approve visual changes efficiently without relying on external services or accounts.
