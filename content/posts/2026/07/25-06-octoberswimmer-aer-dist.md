## Action Summary

**The aer GitHub Action is designed to run Apex unit tests locally without requiring an org. It supports running apex code and testing against metadata next to it, simulating the Salesforce Apex runtime environment with features like SOQL, DML, and governor limits. The action can be used for testing in the CLI or CI and integrates with VS Code and IntelliJ for interactive debugging.**
