## Action Summary

**Summary:** The **sr** GitHub Action automates semantic versioning from conventional commits. It provides a single static binary with Terraform-shaped verbs (`plan`, `prepare`, `release`) to manage releases in a Git repository, including bumping manifest files, writing changelogs, and executing releases safely. Key capabilities include typed publishers for different package managers and workspace-aware behavior for monorepos. The action is particularly useful for CI/CD workflows, automating the release process without manual intervention.
