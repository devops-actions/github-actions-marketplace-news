## Action Summary

The `file-search-on` GitHub Action is a content-type-aware file search tool that uses CEL expressions to filter and search through files in a directory tree based on metadata extracted from each file's attributes. It supports 74 file formats across 13 content-type families, including PDFs, images, videos, and source code. The action allows users to query files by specific criteria, such as author, page count, or GPS location, without relying solely on filenames.
