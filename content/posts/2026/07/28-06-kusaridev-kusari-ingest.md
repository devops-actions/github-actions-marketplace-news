## Action Summary

The kusari-ingest GitHub Action automates the process of ingesting SBOMs, SLSA attestations, and other attestation formats into the Kusari Platform. It simplifies integration by handling authentication credentials and providing optional inputs for additional permissions and configurations. The action supports generating SBOMs directly or scanning container images, and it can capture ingestion results and auto-map components to Kusari components if needed.
