## Action Summary

Sigbound is a GitHub Action that automates parallel AI coding agent runs, merges their work automatically, resolves conflicts using models, and ensures verified merges before landing. It handles non-conflicting changes in parallel, flags low-confidence cases for review, verifies every merge on builds, and self-repairs broken builds by sending them back to agents. The action uses a user-provided model for planning, agent execution, conflict resolution, and repair, and runs on top of plain Git with no server or lock-in.
