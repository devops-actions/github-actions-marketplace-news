## Action Summary

This GitHub Action mirrors GitHub milestones into Jira Cloud epics, ensuring each milestone is converted into an epic with automatic updates based on changes to the milestone's title, description, labels, and due date. The action is read-only and idempotent, making it suitable for automating the synchronization of project roadmaps between both platforms.
