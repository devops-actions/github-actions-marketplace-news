## Action Summary

The Secrets Reader Action is a GitHub Action designed to parse and extract data from JSON-stringified secrets (or params) based on specified nested key paths. It outputs the values of these keys in a simple, user-friendly format for integration testing across multiple environments. The action allows for dynamic naming of output variables and supports configuration through inputs such as `secrets` and `keys`.
