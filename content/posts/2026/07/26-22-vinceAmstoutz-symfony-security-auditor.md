## Action Summary

The Symfony Security Auditor is an AI-powered tool designed to automate security auditing of Symfony applications. It uses a two-agent model—Attacker and Reviewer—to find vulnerabilities that traditional static analysis tools miss. The auditor provides comprehensive reports in various formats (console, JSON, SARIF, HTML, Markdown) and supports dry-run mode for cost estimation without making LLM calls. It can be used as a standalone CLI tool or integrated into Symfony applications via the bundle.
