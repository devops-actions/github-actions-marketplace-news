## Action Summary

This GitHub Action automates policy enforcement in CI using Verdicter, a tool for evaluating sandbox steps against live policies. It checks PRs for compliance with predefined scenarios and ensures no policy regressions reach production. The action requires a Verdicter API key to authenticate and runs in a CI workflow, providing detailed step-by-step results and the ability to fail the check based on unexpected decisions or post comments on pull requests.
