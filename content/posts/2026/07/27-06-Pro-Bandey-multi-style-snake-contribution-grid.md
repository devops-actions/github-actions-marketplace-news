## Action Summary

This GitHub Action automates the creation of a contribution grid animation for multiple snake styles, shapes, and backgrounds. It automatically detects the repository owner and generates five unique styles, including light, dark, ocean, dracula, and hacker themes. The generated assets include SVGs and GIFs for social sharing, and it includes an automated gallery to preview all assets in one place.
