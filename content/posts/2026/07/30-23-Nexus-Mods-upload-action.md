## Action Summary

This GitHub Action automates the process of uploading a new version of a file to NexusMods using their v3 API. It solves the problem of manually managing the upload of mod files and integrates seamlessly into CI/CD workflows, providing features such as archiving existing versions, setting primary download options, and updating mod versions. The action requires an API key and the necessary file ID, along with version details and optional metadata like display name and description.
