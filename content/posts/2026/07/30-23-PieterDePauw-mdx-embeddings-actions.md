## Action Summary

This GitHub Action automates the process of converting markdown files into embeddings using OpenAI and storing them in a Postgres/Supabase database. It enables vector similarity search within your documentation and website by integrating with the `headless-vector-search` repository. The action allows you to generate embeddings for your docs, store them in Supabase, and query them from your site using the provided instructions in the linked repository.
