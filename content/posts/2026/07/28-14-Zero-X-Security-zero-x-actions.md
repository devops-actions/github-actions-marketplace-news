## Action Summary

This GitHub Action, Zero-X Security Scan, automates security scans on the Zero-X Cloud platform from your GitHub Actions workflows. It triggers a scan via the Zero-X API, polls until it completes, and outputs a link to the scan results. The action is designed to automate security checks for repositories connected in Zero-X Cloud, providing a streamlined way to ensure code quality and security during development and deployment processes.
