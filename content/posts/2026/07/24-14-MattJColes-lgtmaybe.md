## Action Summary

The lgtmaybe GitHub Action reviews PRs by analyzing code changes and surrounding lines to identify potential issues such as logic errors, security vulnerabilities, and missing tests. It provides inline review comments and a summary of findings, helping reviewers focus on the most critical changes in context. The action supports multiple review levels (info through critical) and can be configured to run different presets based on branch status.
