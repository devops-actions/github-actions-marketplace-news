## Action Summary

Argus is a GitHub Action that automates AI code review by running multiple specialized reviewers in parallel, then using an evidence-based curator to verify findings before posting review comments. It aims to optimize recall rather than precision, allowing it to find more real bugs while keeping false positives manageable.
