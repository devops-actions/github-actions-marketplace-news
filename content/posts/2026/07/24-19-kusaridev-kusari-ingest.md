## Action Summary

This GitHub Action automates the process of uploading SBOMs, SLSA attestations, and other artifacts to the Kusari Platform from a GitHub workflow. It simplifies integration by handling authentication credentials and provides options to generate SBOMs automatically or manually. Key features include capturing ingestion results for machine-readable IDs and ensuring components are mapped if needed.
