## Action Summary

The Oculum Security Scan action is a GitHub Action that automatically scans codebases for security vulnerabilities using AI-powered detection. It can detect prompt injection, hardcoded secrets, SQL injection, XSS, and other common security issues. The action supports both the free tier (pattern matching) and validated scan tiers (AI-assisted validation). It provides PR comments and inline annotations on diffs, integrates with GitHub, and offers various customizable options for scanning depth and fail thresholds.
