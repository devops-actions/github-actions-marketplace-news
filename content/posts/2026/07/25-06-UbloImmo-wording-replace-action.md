## Action Summary

This GitHub Action automates the replacement of French words or phrases with specified aliases in Lingui PO catalog files while preserving correct grammar and agreement. It supports replacing words in a single file or batches of files using directories, providing detailed change logs for traceability. The action uses Morphalou 3.1 for language lexical database, SpaCy for NLP analysis, and Lingui conf for PO catalog parsing and serialization.
