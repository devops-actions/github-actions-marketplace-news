## Action Summary

The Roborazzi Golden Snapshots Action automates the process of generating, reviewing, and comparing golden screenshots in a GitHub repository. It runs a specified rendering command to generate goldens, compares them with the base ref, and publishes a diff gallery and reference PR if changes are found. The action supports various renderers and is designed to be flexible and generator-agnostic.
