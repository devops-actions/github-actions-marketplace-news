## Action Summary

The Supabase Storage Upload Action automates the process of uploading files from a GitHub Actions workspace to Supabase Storage. It allows users to specify configuration settings, including bucket names, RLS policies, and file paths, to upload specific files to the cloud storage service. The action supports both dry runs and actual uploads, with options to upsert objects and set cache control settings for each file.
