## Action Summary

This GitHub Action automates the setup of Soft-RoCE on Ubuntu GitHub Actions runners by configuring RDMA networking interfaces. It automatically selects an interface based on the default route, allowing users to override it with specific settings for device naming. The action provides outputs for the selected interface and device name, facilitating further automation tasks in workflows.
