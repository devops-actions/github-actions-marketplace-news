## Action Summary

The cibuild action automates iOS and Android CI setup by generating CI/CD pipelines from YAML configuration files. It automatically detects platform, generates default settings, collects secrets from disk, and provides an interactive wizard for customizing the pipeline. Users can run pipelines locally or on remote runners, validate only, or skip validation during execution. The tool also supports importing existing pipeline YAML files and managing secrets securely.
