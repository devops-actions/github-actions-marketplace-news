## Action Summary

This GitHub Action reshapes a generated Postman Smoke collection into an ordered smoke journey using one explicit flow path. It solves the problem of automating the creation and ordering of smoke test flows within the Postman API, providing optional OAuth2 authentication injection for API keys. The key capabilities include automatic workflow generation from OpenAPI specs or user-defined manifests, runtime credential injection, and support for EU data residency configurations.
