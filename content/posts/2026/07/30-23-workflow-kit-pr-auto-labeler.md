## Action Summary

Automatically label pull requests based on code changes and metadata. This action helps developers track changes to UI elements, styles, database migrations, and more without manual intervention. It uses customizable rules to apply labels to pull requests automatically. Users can easily enable specific rules by specifying them in their GitHub Actions workflow file.
