## Action Summary

The Secrets Reader Action is a GitHub Action that parses JSON-stringified secrets to extract values at specified nested key paths and dynamically outputs them as simple key-value pairs. It is particularly useful for integration testing, allowing users to easily manage environment-specific credentials within their workflows. The action supports dynamic naming of output variables based on the last key in each path.
