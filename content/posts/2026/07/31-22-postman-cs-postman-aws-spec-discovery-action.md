## Action Summary

This GitHub Action automates the discovery and export of API specifications from AWS services using only existing AWS credentials. It automatically detects supported providers based on IAM permissions, checks for existing specs in the repository before calling AWS APIs, and integrates with Postman to facilitate spec import into collections and generate contract checks. The action is part of a larger suite of actions designed to streamline API onboarding processes.
