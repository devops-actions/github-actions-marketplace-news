## Action Summary

The `vibecheck` GitHub Action automates code quality and security checks on AI-generated code. It catches common patterns that AI tools tend to introduce, such as hardcoded secrets, insecure practices like `eval()`, and issues related to error handling. The action runs locally without requiring installation or API keys, making it accessible for developers with Python environments.
