## Action Summary

This GitHub Action automates the process of syncing Docusaurus documentation translations by watching changes in source docs and creating translation PRs based on updates or missing files. It helps product and developer-tool teams manage multiple language versions of their Docusaurus content efficiently. The action supports both English to other languages and vice versa, using APIs like DeepSeek for translation services.

## What's Changed
