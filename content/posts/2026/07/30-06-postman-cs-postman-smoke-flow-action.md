## Action Summary

This GitHub Action reshapes a generated Postman Smoke collection into an ordered journey using one explicit flow path. It automates the process of creating and ordering smoke tests based on OpenAPI specifications, with optional OAuth2 authentication and API key injection. The action is part of the Postman API Onboarding suite and can handle various regions and credentials securely through Postman tokens.
