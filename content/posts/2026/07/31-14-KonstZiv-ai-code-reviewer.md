## Action Summary

AI ReviewBot is an AI-powered code review tool that leverages Google Gemini or Mistral AI to analyze and provide inline suggestions directly on GitHub and GitLab PRs. It helps identify vulnerabilities, suggests improvements, and highlights best practices, all while being transparent about metrics and using adaptive language responses based on the repository's language. The bot automatically discovers project details before each review to avoid duplicate feedback from CI pipelines. Users can customize AI settings through environment variables.
