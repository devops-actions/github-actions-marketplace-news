## Action Summary

This GitHub Action (`aer`) automates the execution of Apex unit tests locally without relying on an org. It supports running Apex code and tests, executing anonymous Apex, and stepping through Apex logic with an interactive debugger using VS Code or IntelliJ. The action provides a local environment where developers can verify their Apex code's functionality and identify issues before deploying to Salesforce.
