## Action Summary

The GitHub Action `ohtensorplay/hub-sync` synchronizes a GitHub repository or folder into a MEGA Hub model, dataset, Space, or MCP repository, handling file uploads, deletions, and direct links to the workflow summary. It supports OIDC authentication, allows customization of repo type, subdirectory, revision, and sync behavior, and can handle empty selections.
