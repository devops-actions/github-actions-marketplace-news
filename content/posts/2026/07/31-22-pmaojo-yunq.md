## Action Summary

**Summary:**
Yunq is a static analysis platform in Rust designed to protect AI and coding agents by analyzing their code before it reaches disk. It provides a single binary that supports multiple languages without the need for JVMs or servers, offering a guardrail for AI agent write access and a language server for automated code reviews. The tool includes features like rule-based quality gates, taint analysis, and remediation to ensure high-quality code across various programming languages.
