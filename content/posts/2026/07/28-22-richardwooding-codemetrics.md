## Action Summary

The GitHub Action `codemetrics` automates the computation of cyclomatic and cognitive complexity metrics across multiple programming languages. It provides a simple CLI tool to analyze code complexity and integrates with GitHub Actions to enforce pull request complexity gates, ensuring that functions modified in PRs do not exceed predefined thresholds. The action supports over 17 programming languages using tree-sitter for language-specific parsing.
