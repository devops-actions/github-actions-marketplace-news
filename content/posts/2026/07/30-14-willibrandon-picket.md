## Action Summary

Picket is a MIT-licensed secrets scanner for .NET that provides Gitleaks-compatible command surface, Native AOT release binaries, dotnet tool packages, and embeddable libraries. It automates the scanning of staged, unstaged, and untracked Git changes, Hugging Face models, datasets, Spaces, and buckets with read-only tokens stored in environment variables, and GitLab issues, comments, releases, and release assets. The action is available for GitHub Actions and Azure Pipelines, with options to upload SARIF reports.
