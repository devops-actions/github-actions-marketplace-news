## Action Summary

ReviewGate is an open-source GitHub Actions-based tool that automates PR reviews by calling OpenRouter's API with the user's own API key. It provides a `0-5` confidence score, one canonical summary comment per PR, and structured JSON output. Key features include visibility of review scores, configurable review angles, and automatic maintenance of PR summaries on reruns.
