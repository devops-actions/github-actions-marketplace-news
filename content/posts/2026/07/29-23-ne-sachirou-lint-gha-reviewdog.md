## Action Summary

The lint-gha-reviewdog GitHub Action automates linting of GitHub Actions files using `actionlint`, `zizmor`, and `ghalint`. It posts feedback via `reviewdog` for pull requests and normal CI failures on pushes, centrally manages tool versions, and provides optional per-tool execution. The action requires a GitHub token and runs inside a normal job.
