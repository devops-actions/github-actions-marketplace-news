## Action Summary

Argus is a GitHub Action that automates code review using multiple AI reviewers in parallel. It optimizes for recall by running multiple focused lenses to catch bugs while minimizing false positives. The action includes an evidence-based curator to verify findings and only dismisses issues with cited quotes, ensuring accurate and effective reviews.
