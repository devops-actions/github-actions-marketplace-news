## Action Summary

This GitHub Action automates running CI tests in OpenEuler. It supports various releases and architectures, including x86_64, aarch64, riscv64, and loongarch64. The action allows users to run commands or execute scripts within the OpenEuler VM, passing environment variables and files. Users can also choose from different synchronization methods like rsync, sshfs, nfs, or scp, providing flexibility in how they transfer data between their host machine and the VM.
