## Action Summary

The NoyanSecOps GitHub Action automates security scanning across various tools such as Gitleaks, Semgrep, Trivy, Checkov, and Hadolint. It integrates these tools into CI/CD pipelines to detect secrets, application vulnerabilities, infrastructure misconfigurations, and container compliance issues. The action generates SARIF files for Semgrep, Trivy, Checkov, and Hadolint and uploads them as artifacts, providing visibility in the GitHub Security tab or as local files for private repositories without GHAS.
