## Action Summary

This GitHub Action automates the process of linting XSL stylesheets using the xslint tool. It provides a simple and user-friendly way to integrate static analysis into CI pipelines, with default formatting for inline annotations on pull requests. The action supports various inputs such as files to check, suppress specific checks, and output formats like GitHub annotations or SARIF reports.
