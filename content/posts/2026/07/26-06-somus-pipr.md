## Action Summary

Pipr is a tool that automates AI code review across multiple platforms, including GitHub, GitLab, Azure DevOps Services, and Bitbucket Cloud. It uses Code Host Adapters to ensure provider-neutral setup, leveraging TypeScript to define workflows and policies in `.pipr/config.ts`. Pipr runs AI reviews by building a deterministic Diff Manifest, executing Pi for structured output, validating findings against commentable ranges, and publishing main review comments plus capped inline comments. The tool keeps the review runtime and policy in your repository, allowing you to compose workflows using TypeScript.
