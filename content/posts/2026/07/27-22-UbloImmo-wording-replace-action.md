## Action Summary

The Wording Replace Action is a GitHub Action that automates the replacement of French words or sentences with specified aliases in Lingui PO catalog files while maintaining correct grammar and agreement. This tool is useful for adapting application wording to different contexts, such as gendered alternatives or custom terminology. The action can replace words and phrases in single PO files or batches using directories, and logs details of the changes for traceability.
