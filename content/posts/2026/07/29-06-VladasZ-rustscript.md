## Action Summary

The RustScript action provides a lightweight interpreter and automation tool for running Rust scripts without compiling them. It supports basic Rust syntax and can execute script files directly or as command-line arguments. The action automates tasks like running scripts, validating code with Cargo, and building native binaries for CPU-intensive scripts. It also includes features to list supported methods per receiver and engine, clear cached checks and builds, and update the tool version.
