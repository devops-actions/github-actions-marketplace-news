## Action Summary

Sigbound is a GitHub Action designed to automate the process of running multiple AI coding agents in parallel and merging their work automatically. It resolves conflicts with a model, ensures every merge passes your build and test commands, and gates them using your own verification command. The tool handles merging non-conflicting changes in parallel and provides features such as file lanes, landing policies, and run parking.
