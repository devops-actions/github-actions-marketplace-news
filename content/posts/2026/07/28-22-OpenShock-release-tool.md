## Action Summary

This GitHub Action, `release-tool`, automates semver releases by reading change files in `.changes/` and applying the appropriate release strategy based on branch configuration. It supports stable, prerelease, and no-tag builds, with options to write CHANGELOGs and create tags or not, depending on the branch context. The tool is designed for CI integration and can be installed via binary downloads or Go packages, making it easy to integrate into development workflows.
