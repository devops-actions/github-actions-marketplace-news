## Action Summary

This GitHub Action builds a deterministic `.mpk` file from a MicroPythonOS app folder by ensuring fixed timestamps, sorted entries, and stored (uncompressed) files. It automates the bundling process without requiring any modifications to the app layout, as it uses standard conventions like `MANIFEST.JSON`. The action provides a reusable solution for packaging MicroPythonOS apps in a reproducible manner.
