## Action Summary

This GitHub Action automates SST (Serverless Stack) operations such as deploying, diffing infrastructure changes, and removing stacks. It consolidates multiple composite actions into a single distributable solution, making it easy to integrate into GitHub workflows. The action supports various runtime environments and provides customizable output formats for PR comments and workflow summaries.
