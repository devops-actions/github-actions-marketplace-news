## Action Summary

The GitHub Action automates the process of building and deploying static frontend applications to Parkstatic, a service that handles various frameworks' standard build scripts. It supports Vite SPAs, TanStack Start, React Router, Remix, Astro, SvelteKit, Nuxt, and other frameworks by running their `build` script and deploying the resulting static output directly or after prerendering with a headless browser if needed. The action ensures that the deployment is confirmed by WordPress before finishing and does not modify the repository.
