## Action Summary

This GitHub Action reshapes a generated Postman Smoke collection to match a curated `flow.yaml`, automating the process of setting up authentication tokens and integrating it with API keys. It solves the problem of manually configuring OAuth2 authorization headers, making it easier to automate smoke testing in a continuous integration environment.
