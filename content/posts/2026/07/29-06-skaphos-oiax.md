## Action Summary

Oiax is a declarative Git branch promotion reconciler designed to automate the management of environment promotions in GitOps repositories. It ensures that only one active managed pull request exists per diverged edge in the promotion graph, automatically handles backflow, and provides templatable PR titles and bodies for auditable sign-offs. The tool checks git 2.45 or newer versions and supports a GitHub Action execution model.
