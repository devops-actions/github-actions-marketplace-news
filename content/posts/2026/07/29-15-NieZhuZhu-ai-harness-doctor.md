## Action Summary

**AI Harness Doctor** is an open-source tool developed by NieZhuZhu that automates code review and documentation audits to ensure coherent and maintainable agent instructions across various repositories. It helps users consolidate scattered guidance into one centralized `AGENTS.md` file, manages tool-specific files as pointers, and measures the effectiveness of the resulting harness by improving agent answers and reducing latency. The tool also provides a zero-install, read-only checkup and can verify the Node and Python runtime environments used in the repository.
