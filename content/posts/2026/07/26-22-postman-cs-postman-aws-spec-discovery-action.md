## Action Summary

This GitHub Action automatically discovers and exports API specifications from AWS services using only existing AWS credentials. It handles region selection, automatic repository resolution, and provides zero-config setup to convert the discovered specs into Postman collections, OpenAPI-based contract checks, smoke tests, mocks, monitors, repo artifacts, and CI runs.
