## Action Summary

This GitHub Action automates the setup of Oracle Test Pilot for Third-Party Software in GitHub Actions workflows. It provides actions to request and de-provision OCI services, create registration tokens, and skip non-regression testing based on file changes. The action supports Linux platforms and has inputs for specifying actions, OCI services, users, connection string formats, and prefix lists. Outputs include database information and whether tests should be skipped, allowing workflows to reduce execution times for commits that do not affect source code.
