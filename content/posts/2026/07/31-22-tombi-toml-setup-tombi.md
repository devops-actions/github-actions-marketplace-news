## Action Summary

This GitHub Action sets up Tombi, a dependency management tool for TypeScript and JavaScript projects, in your GitHub Actions workflow. It automates the installation process of Tombi CLI based on user-specified options such as version, lock file path, or checksum validation. The action supports various runner environments and provides caching behavior to optimize installation times by reusing previously downloaded files.
