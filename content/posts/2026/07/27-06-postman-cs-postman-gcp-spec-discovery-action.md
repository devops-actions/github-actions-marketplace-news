## Action Summary

The Postman Onboarding: GCP Spec Discovery action automates the process of discovering and exporting OpenAPI specifications from Google Cloud services. It helps in resolving or exporting a specification based on repository context, labels, or specific API IDs, and provides a clear output indicating the resolved source type and specification path. The action is particularly useful for integrating with Postman to automate onboarding processes for APIs hosted on GCP resources.
