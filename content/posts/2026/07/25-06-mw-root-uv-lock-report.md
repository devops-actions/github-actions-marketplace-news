## Action Summary

This GitHub Action, `uv Lock Report`, analyzes changes in `uv.lock` files between base and head commits of a pull request to generate a clear summary of dependency updates. It provides insights into which packages have been added, updated, or removed, including version changes and severity levels (major, minor, patch). This helps reviewers quickly understand the impact of lockfile changes without manually parsing diffs. The action outputs reports in both simple and table formats and can be used as a standalone CLI tool for local development or CI/CD pipelines.
