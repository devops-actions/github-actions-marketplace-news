## Action Summary

**Summary:**

This GitHub Action, Runhuman Issue Tester, automates the process of testing linked GitHub Issues using AI-powered human QA testing. It supports three main modes: auto-detection (default), manual selection by issue number, and dynamic filtering based on queries. The action allows for granular control over test execution, including setting a target duration, handling issues not suitable for testing, and automating actions based on test outcomes.
