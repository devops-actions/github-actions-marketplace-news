## Action Summary

This GitHub Action automates the creation of a Cargo-Rail plan to optimize CI build configurations by identifying the minimum set of dependencies needed for specific branches or pull requests. It provides outputs that help users understand which packages are affected and the necessary cargo arguments for building only those packages. The action does not interfere with existing build, test, cache, release, or publish processes, allowing developers to maintain their current workflows while ensuring CI jobs run efficiently based on the identified changes.
