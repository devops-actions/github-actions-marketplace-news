## Action Summary

This GitHub Action reshapes a generated Postman Smoke collection into an ordered smoke journey using either an explicit `flow-path` or a derived manifest from the OpenAPI spec. It automates the process of creating a structured flow path for testing and helps automate API onboarding tasks, including OAuth2 authentication and API key injection.
