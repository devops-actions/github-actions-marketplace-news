## Action Summary

**Summary:**

This GitHub Action and CLI tool automates the management of rolling minimum-supported versions in Python projects. It reads dependency constraints from a `pyproject.toml` file, evaluates them against a support policy (Scientific Python SPEC 0 is built-in), updates the lower bounds and `requires-python` floor accordingly, preserving existing requirements and formatting. The action supports configurable support windows for both overall project and per-package policies, allowing flexibility in following SPEC 0 or customizing minimum supported versions.
