## Action Summary

RustScript is a tool that interprets Rust code without compiling it fully. It allows running scripts directly or checking them with Cargo without the overhead of a full build process. The action provides features such as running snippets, validating files, and compiling scripts into native binaries. It works on Linux, macOS, and Windows and supports Rust's practical subset, providing type safety and execution speed similar to compiled Rust but without the compile time delay.
