## Action Summary

Pull Request Semver Bumper automates semantic versioning directly within Pull Requests, ensuring that the main branch is always clean and versioned. It supports multiple project types (Maven, NPM, Python, Version Files, Helm) and provides standardized version bumping via Conventional Commits. The action handles version bumps before merging, preventing clutter in history and extra CI runs.
