## Action Summary

VibeGuard is a security scanner designed to detect bugs in AI-generated code. It automates the detection of common security issues such as missing input checks, hard-coded passwords, and skipped login checks, ensuring that risky code is blocked before merging into a project. The action provides inline diagnostics in VS Code, browser-based scanning on web pages, and CI integration to enforce security standards across different environments.
