## Action Summary

This GitHub Action automatically links discovered services from the Postman Insights DaemonSet to relevant workspaces and repositories, making them visible in the API Catalog. It handles configuration of service discovery, workspace management, and integration with Git repositories through human-user credentials, ensuring seamless onboarding into your Postman environment.
