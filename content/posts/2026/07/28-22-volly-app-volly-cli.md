## Action Summary

The `volly-cli` GitHub Action automates the deployment and management of Volly apps from the terminal. It provides commands for signing in, deploying applications, managing app listings, creating and publishing drafts, and listing deployments and tokens. The action supports both interactive sign-in and token-based authentication, with options to stage a build as a draft or publish it directly. It also includes integration with GitHub Actions for seamless deployment workflows, outputting the deploy URL and job ID in the job summary.
