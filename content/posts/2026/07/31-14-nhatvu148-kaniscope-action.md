## Action Summary

Kaniscope is a GitHub Action that uses AI to review pull requests. It posts a line-anchored inline review comment along with a summary comment on the exact lines of a file, helping developers identify potential issues such as SQL injection and missing `await` calls. The action runs on OpenRouter's models, which are cheap and efficient, allowing for quick feedback without affecting code merging or editing.
