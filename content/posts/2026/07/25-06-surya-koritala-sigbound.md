## Action Summary

Sigbound is a GitHub Action that automates the process of running multiple AI coding agents in parallel, merging their results automatically. It helps developers by reducing time spent on conflict resolution and ensures that only code that builds and passes tests lands. The action uses a model to resolve conflicts and flags uncertain cases for review, while also verifying every merge before it is landed.
