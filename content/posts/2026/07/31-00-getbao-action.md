## Action Summary

This GitHub Action automates the deployment of a getbao authentication service to Cloudflare Workers. It downloads versioned release assets, provisions necessary infrastructure using OpenTofu, applies database migrations, deploys the workers, and initializes encryption keys and secrets. The action supports both sandbox and production deployments through environment labels.
