## Action Summary

This GitHub Action automates the process of running Langfuse experiments within a CI pipeline, allowing developers to test their code against predefined datasets. It loads an experiment script, runs it using the appropriate SDK (Python or TypeScript), comments the results on pull requests, and optionally fails the job if a regression is detected. The action also supports managing secrets and pinning specific Langfuse SDK versions, ensuring consistency across different environments.
