## Action Summary

This GitHub Action automates the creation of a Postman workspace from an OpenAPI specification, generating baseline, smoke, and contract collections. It integrates contract tests with OpenAPI request/response/schema/security checks, supporting various protocols like gRPC, SOAP, GraphQL, AsyncAPI, and MCP. The action simplifies the process by handling both public HTTPS URLs and local file paths for spec import, while also providing options to enforce credential preflight checking.
