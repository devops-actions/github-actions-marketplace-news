## Action Summary

The action generates directory listings for GitHub Pages and automates the deployment process using GitHub Actions. It supports generating listings from a specified folder, excluding files or directories, and deploying them to either the same repository's `gh-pages` branch or an external repository. The action can also customize various aspects such as site URL, base path, site name, footer text, and commit messages.
