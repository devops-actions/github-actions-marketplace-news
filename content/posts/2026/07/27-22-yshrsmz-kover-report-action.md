## Action Summary

The Kover Report Action generates and reports code coverage from Kover XML reports for Kotlin/Android projects with multi-module support. It handles single- or multi-module projects, supports both Gradle-based discovery and glob pattern module paths, allows configurable thresholds per module type and name, integrates PR comments with automatic updates, tracks coverage history and trends visually, exports coverage data for other workflow steps, and is optimized for performance and security.
