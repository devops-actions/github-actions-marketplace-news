## Action Summary

This GitHub Action automates the discovery and export of API specifications from AWS services using only your existing AWS credentials. It helps in generating deterministic collections, OpenAPI-backed contract checks, smoke tests, mocks, monitors, repo artifacts, and CI runs by connecting to AWS resources such as API Gateway, AppSync, SNS, EventBridge, Lambda, SSM, etc. The action is part of the Postman API Onboarding suite and is useful when a service already runs on AWS with no need for manual configuration.
