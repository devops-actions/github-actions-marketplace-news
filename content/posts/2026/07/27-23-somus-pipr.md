## Action Summary

Pipr is a code-owned AI review action that automates structured code reviews across various code hosts, including GitHub, GitLab.com, Azure DevOps Services, and Bitbucket Cloud. It uses the Diff Manifest to build deterministic diffs, runs the Pi tool for structured review output, validates findings against commentable ranges, and publishes main review comments with capped inline comments. The action keeps the review runtime and policy in repository code, allowing users to compose workflows using TypeScript.
