## Action Summary

This GitHub Action updates the `## Unreleased` section of a `CHANGELOG.md` file using an AI model. It gathers information from Git history, pull requests, and optionally related repositories to produce a user-focused changelog entry while preserving existing content. For full releases, it consolidates pre-release notes from different branches or tags. The action can be configured with various inputs such as API keys, LLM models, audience types, and prompt extras.
