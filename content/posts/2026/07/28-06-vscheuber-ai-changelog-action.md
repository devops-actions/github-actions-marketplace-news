## Action Summary

The AI Changelog Updater GitHub Action automates the process of updating a `CHANGELOG.md` file by gathering Git history, pull request information, and optional activity from related repositories. It uses an LLM to generate a user-focused changelog entry while preserving existing content in the `## Unreleased` section. For full releases, it consolidates pre-release notes and provides a clean, de-duplicated set of notes for the final stable version. The action is reusable and can be integrated into workflows, with various inputs and outputs for customization.
