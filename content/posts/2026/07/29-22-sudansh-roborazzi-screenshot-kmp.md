## Action Summary

This GitHub Action automates the process of creating and reviewing golden image screenshots for Android projects using Gradle, Roborazzi, or Paparazzi. It captures screenshots, compares them against base references, and opens a pull request with a diff gallery if differences are found. The action is designed to be flexible, allowing for various types of screenshot generators by requiring only the `render-command` input.
