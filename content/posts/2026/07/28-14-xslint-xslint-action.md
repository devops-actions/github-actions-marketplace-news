## Action Summary

This GitHub Action uses the `xslint` tool to lint XSL stylesheets, providing inline annotations on pull-request diffs. It automates the process of identifying and reporting errors in XML schemas or stylesheets used in web development projects. The action supports various formats for output, including SARIF, and allows suppressing specific checks or configuring maximum warnings.
