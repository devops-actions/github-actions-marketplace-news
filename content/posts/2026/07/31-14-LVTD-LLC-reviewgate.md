## Action Summary

ReviewGate is an open-source GitHub Action that automates pull request reviews by integrating with OpenRouter's AI-powered model. It assesses the quality of a PR, provides a visibility score and summary comment, supports maintainer-requested rereviews, and generates structured JSON artifacts for further analysis or integration into CI/CD pipelines.
