## Action Summary

This GitHub Action automates the process of uploading a CycloneDX Software Bill of Materials (SBOM) to Threat Detective, a tool used for verifying and validating the security posture of medical devices. The action handles validation, CVE matching, and regulatory evidence for FDA and EU submissions. It requires setting up a trust policy and OIDC permissions in your GitHub Actions workflow. The action supports uploading SBOMs on various events like pushes to a branch and can override software item details and wait for import completion with configurable settings.
