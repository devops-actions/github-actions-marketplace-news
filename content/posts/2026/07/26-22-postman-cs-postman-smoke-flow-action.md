## Action Summary

This GitHub Action, Postman Onboarding: Smoke Flow, reshapes a generated Postman Smoke collection to match a curated `flow.yaml` and allows for optional runtime auth injection using OAuth2 or API keys. It helps automate the setup of smoke testing configurations in Postman, ensuring that tests are aligned with project workflows and security requirements. The action is part of a larger suite of onboarding tools for Postman projects, making it easier to integrate comprehensive testing into development workflows.
