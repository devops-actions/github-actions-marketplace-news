## Action Summary

The GitHub Action ToQuery/wails3-build-action@v3 automates the build process for Wails.io v3 projects. It installs GoLang and NodeJS, builds the project using specified platforms and options, and optionally uploads results to GitHub or publishes releases on tagged builds. The action supports various configuration options for customizing the build process, including versioning and caching.
