## Action Summary

MotionScore Guard automates animation performance auditing for pull requests by loading pages in a real browser on GitHub runners and grading them with S to F tiers. It supports free access for any repository but provides a paid plan with token-based gating that fails builds if page grades fall below specified thresholds. The action can audit specific paths and upload reports, making it easy to integrate into workflows.
