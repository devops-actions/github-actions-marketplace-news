## Action Summary

The GitHub Action `ToQuery/wails3-build-action@v3` automates the building and packaging of Wails.io v3 projects. It installs GoLang, NodeJS, and runs a build process to generate binaries for different platforms. The action defaults to uploading results to GitHub, including tagged builds which also publish releases. Users can configure various options such as Go version, Wails version, build name, obfuscation, platform, caching, and package upload settings. It supports building for macOS, Windows, and Linux with different architectures.
