## Action Summary

PDF Text Layer Auditor is a Java CLI designed to audit PDF documents for missing or suspicious native text layers. It helps identify pages with no searchable text, broken Unicode mappings, replacement characters, and tiny text below a configurable threshold. The tool also reports on the fonts used on each page. The GitHub Action provides a Docker-based solution that audits all changed PDFs in a pull request, emitting annotations and creating a combined JSON report.
