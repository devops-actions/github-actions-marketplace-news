## Action Summary

This GitHub Action automatically moderates the content of issues, pull requests, and comments using the OpenAI Content Moderation API. It normalizes text, detects inappropriate content, and hides sensitive information by minimizing or closing relevant issues and pull requests. The action supports custom endpoints from various AI providers like GitHub Copilot, OpenAI, Azure OpenAI, Ollama, and any other compatible service.
