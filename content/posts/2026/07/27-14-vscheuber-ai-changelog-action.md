## Action Summary

The AI Changelog Updater GitHub Action automates the process of updating a CHANGELOG.md file by leveraging an LLM to generate a user-focused changelog entry based on recent changes and activity. It can handle both full releases and pre-release versions, merging pre-release notes into the final stable release version. The action is highly customizable with various inputs for controlling the behavior and audience focus.
