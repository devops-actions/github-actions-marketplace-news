## Action Summary

latexbuild automates LaTeX document compilation into PDF format using Docker to containerize a full TeX Live environment without requiring local installation. It provides interactive and non-interactive ways to compile `.tex` files, rebuilds automatically with `--watch`, offers a live browser editor for immediate feedback, and supports building multiple projects simultaneously.
