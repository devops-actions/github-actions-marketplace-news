## Action Summary

The Sprocket GitHub Action automates static analysis of WDL documents, including linting and validation. It supports various actions such as checking, linting, validating JSON inputs against schemas, and formatting WDL files. Users can specify configuration settings in a `sprocket.toml` file for consistent behavior across environments.
