## Action Summary

SSG is a fast static site generator written in Go that transforms Markdown content with YAML frontmatter into a complete website, including features like clean URLs, templates, feeds, search, image processing, and native deployment to various platforms. It supports multiple template engines and provides options for SEO metadata, webp conversion, and responsive images. The action is designed to automate the creation and management of static websites efficiently.
