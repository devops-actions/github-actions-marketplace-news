## Action Summary

The Delivery Autopilot Runner GitHub Action automates the process of creating pull requests for code changes based on tickets from a tracker using an AI pipeline. It ensures that your work is planned, built, and checked within your own GitHub Actions environment, without sending any sensitive data to Tekunda's servers. The action requires an active Delivery Autopilot subscription to function properly, and it provides options for manual setup through the GitHub App or direct workflow creation with specific configurations for authentication and quality checks.
