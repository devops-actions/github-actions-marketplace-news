## Action Summary

The GitHub Action `setup-odoopack` installs the `odoopack` CLI tool and adds it to the system's PATH. It allows users to easily manage Odoo packages by automating tasks such as installing versions, configuring private registries with tokens, and retrieving installation details. The action supports specifying versions, registry URLs, and authentication tokens for a more secure setup.
