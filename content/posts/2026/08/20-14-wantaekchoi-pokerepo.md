## Action Type
This is a **Composite** action.

Go to the [GitHub Marketplace](https://github.com/marketplace/actions/pokerepo-dex) to find the latest changes.

## Action Summary

This GitHub Action automatically updates a Pokémon-themed card on user's repository READMEs, tracking their Pokémon level and adding them to the Pokémon Dex through commits and merged pull requests. The action is configured by modifying a simple line in the repository's README and includes options for scheduling and manual triggering.

## What's Changed

First release.

One Pokémon per repository. Commits level it up, merged pull requests add it to your Dex.

A fork is a Dex *seen*; a merged pull request is *caught*. Commits and merges are worth more where you do not own the repository, because a merge is someone else accepting the work. Stars on the upstream decide rarity.

Setup is four steps in the [README](https://github.com/wantaekchoi/pokerepo#setup). Reference `wantaekchoi/pokerepo@v1` to follow the major version, or `@v1.0.0` to pin.

Species data, experience curves and sprite addresses come from [PokéAPI](https://pokeapi.co) under BSD-3-Clause. No Pokémon artwork is stored in this repository or its releases.
