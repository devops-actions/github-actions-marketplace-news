## Action Summary

Picket is a secrets scanner for .NET that provides a command-line tool, an interactive report triage companion, and native AOT releases. It can scan staged Git changes, Hugging Face models, GitLab issues, and other resources using read-only tokens stored in environment variables or secret files. The action can be integrated into GitHub Actions and Azure Pipelines, and it offers agent guards for Codex and Claude hook events.
