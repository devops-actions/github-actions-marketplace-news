## Action Summary

Skeptic is a GitHub Action that checks if automated test passes mean anything by injecting known bugs into pinned commits of real upstream repos, auditing the resulting patch. The tool helps identify false positives and ensures verification without access to the original repo. It evaluates its performance against baseline results using 12 tasks across two upstream repos, with varying detection settings and FP counts.
