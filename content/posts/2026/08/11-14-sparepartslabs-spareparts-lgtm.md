## Action Summary

This GitHub Action automates the process of asking reviewers questions about pull requests they approve, generating the questions from the diff. It solves the problem of ensuring that everyone reads the pull request before approving it and provides a user-friendly experience by offering unlimited attempts without scoring or marking reviews as failed. The action uses an agent matrix supported by Claude, Codex, Cursor, GitHub Copilot, Gemini, and OpenCode to generate the questions.
