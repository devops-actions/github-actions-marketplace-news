## Action Summary

This GitHub Action automates React Native over-the-air updates using the Aether push SDK. It simplifies CI/CD processes by releasing updates to apps on iOS and Android platforms, providing options like customizing deployment channels, rollouts, and metadata. The action supports both `release` and `release-react` commands and handles various configuration inputs to streamline the update release process in a CI pipeline.
