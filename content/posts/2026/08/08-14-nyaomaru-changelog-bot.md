## Action Summary

The `@nyaomaru/changelog-bot` GitHub Action automates the process of creating polished changelog entries by combining commit history, PR titles, and release notes. It solves problems related to tedious manual changelog writing by generating concise entries automatically. The action supports LLM superpowers for tone-aware summaries or uses a robust heuristic fallback if necessary. It can open PRs with updated changelogs and maintain compare links and release notes in the correct format. Safe defaults are included to prevent issues like duplicate versions and failed releases due to AI unavailability. The tool is designed to be used as a GitHub Action, reusable workflow, or CLI, reducing the need for fragile scripting.
