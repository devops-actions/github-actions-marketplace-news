## Action Summary

This GitHub Action automates the process of updating a plugin in a Claude Code marketplace manifest by applying specified changes. It ensures that the update is validated and lands as a signed commit, satisfying branch protection requirements. The action supports manual triggering through a `workflow_dispatch` event or can be triggered from another repository via a `repository_dispatch` event.
