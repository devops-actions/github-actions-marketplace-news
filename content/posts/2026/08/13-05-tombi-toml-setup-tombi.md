## Action Summary

This GitHub Action sets up [Tombi](https://github.com/tombi-toml/tombi) in your GitHub Actions workflow. It allows you to install Tombi CLI versions, either by specifying a version number, using a lock file, or with checksum verification for the downloaded archive and executable binary. The action supports caching and can be configured to use a custom cache directory.
