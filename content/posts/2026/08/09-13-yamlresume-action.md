## Action Summary

The YAMLResume GitHub Action automates the process of building professional resumes from YAML files using the YAMLResume CLI. It supports multiple resume builds, customizable build options, and outputs generated file paths for subsequent steps. The action can generate both LaTeX and PDF files and is suitable for use in workflows to handle custom PDF pipelines or to upload artifacts.
