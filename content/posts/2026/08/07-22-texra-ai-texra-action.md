## Action Summary

This GitHub Action, `texra-action`, automates the integration of [TeXRA](https://texra.ai) tools into CI/CD workflows. It allows users to review pull requests inline using TeXRA's AI agents or run any agent headlessly in CI environments, consuming and displaying the results directly within PRs. The action uses `@texra-ai/cli` to execute TeXRA commands and can be configured to post inline comments or generate summary reviews.
