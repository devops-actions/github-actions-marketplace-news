## Action Summary

The `file-search-on` GitHub Action is a content-type-aware file search tool that leverages CEL (Cloud Execution Language) expressions to filter files based on metadata and content type-specific attributes. It supports 74 file formats across thirteen content-type families, including PDFs, images, audio, video, office documents, eBooks, plain text, archives, compiled binaries, email messages, and source code. The tool can be used to query files in a directory tree by typed content-type attributes directly from Claude Code or as a standalone CLI utility.
