## Action Summary

This GitHub Action automates running CI jobs on MidnightBSD. It supports a variety of releases and architectures, including x86_64. The action allows users to pass environment variables, run commands, and share code between their host machine and the VM using rsync, sshfs, nfs, or scp. Users can specify which shell to use within the VM. The latest major version is recommended for use, with instructions on migrating from previous versions.
