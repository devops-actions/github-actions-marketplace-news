## Action Summary

AI ReviewBot is a GitHub Action that uses AI to provide intelligent code review feedback directly within pull requests and merge requests. It analyzes your repository's code, identifies vulnerabilities, provides inline suggestions, and highlights good practices. The action automatically discovers the project's languages, frameworks, and CI pipeline to avoid duplication of feedback. You can customize its behavior with environment variables such as discovery settings and API keys for AI providers like Google Gemini or Mistral.
