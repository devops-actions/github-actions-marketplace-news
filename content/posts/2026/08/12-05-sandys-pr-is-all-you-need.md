## Action Summary

This GitHub Action automatically manages multiple pull requests per active branch, enabling AI code review tools to process direct commits to private branches without the need for manual intervention or additional tokens. It keeps draft PRs open as surfaces for review and retires them when branches are merged, deleted, or become inactive. The action uses a single `GITHUB_TOKEN` for all operations and has no secrets or configuration required.
