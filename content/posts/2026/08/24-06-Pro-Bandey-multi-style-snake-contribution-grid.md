## Action Summary

This GitHub Action generates a dynamic animation of a Snake contribution grid for your GitHub repository using multiple styles, including 5 unique themes. It automatically detects the repository owner, creates SVGs and GIFs of different shapes and backgrounds, and updates a `README.md` branch with all assets. The generated content is suitable for personal or professional use in profiles to showcase contributions.
