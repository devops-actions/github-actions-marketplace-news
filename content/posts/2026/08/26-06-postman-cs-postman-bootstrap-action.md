## Action Summary

The Postman Onboarding: Workspace Bootstrap GitHub Action automates the creation of a Postman workspace from an OpenAPI specification, generating baseline, smoke, and contract collections with executable tests. It supports various protocols and provides multi-protocol contract assertions grounded in RFCs. The action can be used for both Git-first specs and public HTTPS URLs, requiring either `spec-url` or `spec-path`. Users must provide a Postman access token to operate on assets.
