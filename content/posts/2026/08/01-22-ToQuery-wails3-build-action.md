## Action Summary

The GitHub action `ToQuery/wails3-build-action@v3` automates the process of building Wails.io projects. It installs GoLang and NodeJS, runs a build for specified platforms, and optionally uploads artifacts to GitHub or publishes releases on tagged builds. The action supports various configurations such as Go version, Wails version, build platform, and options like obfuscation and caching.
