## Action Summary

The yunq action is a tool that provides static analysis and code quality checks in Rust. It automates the process of analyzing code before it reaches disk, ensuring that AI agents are judged by the same guardrail as the platform itself. The key capabilities include:

- Analyzing code written in multiple languages
- Ensuring compliance with coding standards and policies
- Providing real-time feedback on code quality and potential issues
