## Action Summary

AI ReviewBot is an AI-powered code review tool that automates the process of analyzing and commenting on code in GitHub and GitLab. It uses Google Gemini or Mistral AI to identify vulnerabilities, suggest improvements, and highlight good practices with inline suggestions that can be applied directly within PRs or MRs. The tool provides transparent metrics such as tokens used, latency, and estimated cost, helping developers understand the impact of their changes before merging into the main branch.
