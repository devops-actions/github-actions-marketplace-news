## Action Summary

This GitHub Action automates the management of Xcode Swift Package Manager (SPM) dependencies. It resolves all SPM packages, detects changes, and generates an HTML dependency report with version diffs, repo links, and type badges. Optionally, it outputs a CycloneDX SBOM for machine-readable bill of materials and classifies packages as App or Development automatically. The action is useful for maintaining consistent and secure dependencies across projects.
