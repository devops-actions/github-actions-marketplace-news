## Action Summary

SSG is a fast static site generator written in Go that converts Markdown with YAML frontmatter into a complete website. It automates tasks such as content building, template rendering, SEO metadata, and deployment to various platforms like GitHub Pages, Netlify, Vercel, and Cloudflare Pages. The action provides an easy way to generate static websites using Markdown and YAML files, with options for custom themes, templates, and deployment services.
