## Action Summary

The Lineaje Scan Action automates the scanning of container images and source code for vulnerabilities using the Lineaje platform. It prints a vulnerability summary and generates a fix plan when requested, allowing users to rebuild and rescan images to verify fixes. The action supports various programming languages and can scan both Dockerfile-based and source-based projects.
