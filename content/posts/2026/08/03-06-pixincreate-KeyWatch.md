## Action Summary

The KeyWatch GitHub Action automates secret scanning by scanning files and directories, detecting secrets such as passwords, keys, and tokens. It provides a fast and efficient way to scan code repositories or any directory for sensitive information. The action is compatible with various runners, including Linux x64 and macOS x64/arm64, and supports different exit modes for handling findings.
