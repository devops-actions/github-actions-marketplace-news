## Action Summary

This GitHub Action reshapes a generated Postman Smoke collection into an ordered smoke journey using one explicit flow path or a derived manifest from the OpenAPI spec. It automates the process of organizing and running tests, providing options for OAuth2 and API key authentication. The action is part of the larger Postman API Onboarding suite and can be used to streamline the onboarding process for new projects.
