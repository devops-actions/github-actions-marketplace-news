## Action Summary

This GitHub Action automates the deployment of an application to a [Miabi](https://github.com/miabi-io/miabi) control panel. It uses the `miabi` CLI to deploy images from a GitHub repository without requiring SSH access or Docker socket. The action supports customizable deploy strategies and provides a quick start guide for setting up API tokens, environment variables, and integrating it into workflows.
