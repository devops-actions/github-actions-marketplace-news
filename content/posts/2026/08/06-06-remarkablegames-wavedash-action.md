## Action Summary

This GitHub Action automates the process of uploading and publishing web games to Wavedash. It can handle both manual configuration files (`wavedash.toml`) and auto-creation based on entrypoint HTML. The action supports various inputs such as API token, game ID, upload directory, entrypoint file, SDK version, and release details for publishing.
