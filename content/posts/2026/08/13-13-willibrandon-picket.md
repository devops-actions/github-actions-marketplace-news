## Action Summary

Picket is a MIT-licensed secrets scanner for .NET that provides a Gitleaks-compatible command surface, Native AOT release binaries, dotnet tool packages, and embeddable libraries. It automates scanning staged, unstaged, and untracked non-ignored Git changes, as well as GitLab issues, comments, releases, and release assets using various authentication methods. The action supports CI integrations through GitHub Actions and Azure DevOps, with options for customizing reports and handling findings.
