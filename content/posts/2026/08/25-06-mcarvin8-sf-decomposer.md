## Action Summary

The GitHub Action, `sf-decomposer`, automates the process of breaking down large Salesforce metadata XML files into smaller, more manageable pieces for version control and deployment. It supports decompiling and recomposing metadata in various formats like XML, JSON, YAML, and JSON5. The action runs as a standalone tool without requiring the Salesforce CLI or plugin installation, making it suitable for CI/CD environments where these tools are not available.
