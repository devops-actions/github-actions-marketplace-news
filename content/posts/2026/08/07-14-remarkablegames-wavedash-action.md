## Action Summary

This GitHub Action automates the process of uploading and publishing web game files to Wavedash. It simplifies the integration of Wavedash into game development workflows, handling configuration file creation and injection of the Wavedash SDK as needed. The action supports various inputs such as API token, game ID, upload directory, entrypoint, SDK version, and options for building and publishing games with release notes.
