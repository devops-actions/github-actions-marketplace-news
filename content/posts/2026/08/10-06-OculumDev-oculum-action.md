## Action Summary

The Oculum Security Scan action is a GitHub Action that detects AI-era security vulnerabilities in LLM-powered applications. It combines both AI-assisted validation and traditional static application security testing (SAST) to find hardcoded secrets, SQL injection, XSS, and more. The action supports both the free tier for pattern-matching scans at no cost and validated scans using an API key for enhanced accuracy and lower false positives. It provides real-time feedback through PR comments and inline annotations on code diffs, making it easy to identify and address security issues early in the development cycle.
