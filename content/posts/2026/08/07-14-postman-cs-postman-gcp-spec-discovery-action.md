## Action Summary

This GitHub Action automates the process of discovering and exporting OpenAPI specifications from Google Cloud services, such as BigQuery, Cloud Functions, and Firestore, using Application Default Credentials or Workload Identity Federation. It helps developers integrate their GCP resources seamlessly into Postman for onboarding, reducing manual effort by automatically resolving service configurations based on labels or specific API IDs.
