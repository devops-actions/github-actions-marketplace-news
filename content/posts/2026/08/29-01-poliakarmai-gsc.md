## Action Summary

GSC is a GitHub Action that performs SAST (Static Application Security Testing) and security audits on code repositories, providing features like PoC auto-generation, proof-of-fix, self-healing CI, and LLM-verification. It helps developers identify and fix vulnerabilities in their projects efficiently, and offers BYO-LLM support to customize the risk assessment process.
