## Action Summary

Sentinel Review is an AI-powered security review GitHub Action that reads pull request diffs, reasons about them using Claude, and posts findings as inline comments. It helps catch reasoning-based issues like hardcoded secrets, SQL injection, auth bypasses, and missing input validation on untrusted data. The action is a complementary layer to static analysis tools like CodeQL and Snyk, catching logic-level issues that pattern matchers might miss.
