## Action Summary

This GitHub Action reviews pull requests with an adversarial senior reviewer by posting **APPROVE**, **COMMENT**, or **REQUEST CHANGES** with inline comments on the diff. It supports multiple providers like Grok, ChatGPT, Claude, and Gemini to provide different types of reviews based on the provider's capabilities and models. The action automates code review tasks and is designed to be run after CI passes on pull requests only.
