## Action Summary

`.NET Quality Enforcer` is a configurable quality gate for .NET, Python, Java, Kotlin, TypeScript, JavaScript, Go, and Rust repositories. It provides reusable checks to enforce architectural boundaries, code size and complexity, source and namespace layout, public API XML documentation, test architecture and naming conventions, and Cobertura repository, diff, and branch coverage. The enforcer provides the analysis engine and tests while consuming repositories provide policies, baselines, source layout, layer names, thresholds, and CI paths.
