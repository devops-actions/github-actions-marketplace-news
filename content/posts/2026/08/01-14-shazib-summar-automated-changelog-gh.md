## Action Summary

The GitHub Action `automated-changelog-gh` generates and updates a CHANGELOG.md file based on git tags and commit history. It groups commits using Conventional Commits and renders them in Keep a Changelog format. The action can regenerate the entire changelog or update it for a newly released tag, providing links to GitHub compare views and PRs.
