## Action Summary

The GitHub Action `claude-code-marketplace-manager` automates the process of updating plugins in a Claude Code marketplace manifest. It supports both manual and automated triggering, allowing users to re-pin plugins directly from their repositories or external sources. The action ensures that only specified changes are made, preserving existing formatting and comments, and signs commits server-side through a GitHub App for verification against branch protection rules.
