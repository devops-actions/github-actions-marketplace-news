## Action Summary

The GitHub Action Integrations-dev/GitHub-Informer@v1 automates the integration between GitHub and Zoho Cliq, allowing users to send notifications about various GitHub events directly to their Cliq channels. It requires a webhook token and channel API endpoint or unique name, which can be added as a GitHub Secret. Users can customize messages for individual events or set a default message for all events. Additionally, it provides shortcuts to include variables like the event type, action, user, repository, branch/tag, workflow, etc., in their notifications.
