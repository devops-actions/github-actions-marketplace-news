## Action Summary

This GitHub Action sets up Tombi, a tool for managing and securing configuration files, in your CI/CD workflows. It simplifies the installation process by allowing users to specify different versions, use lock files for consistency, and verify checksums for integrity. The action supports various runners and provides options to manage cache behavior effectively.
