## Action Summary

The Rabbit Automation Action automates the deployment of cloud infrastructure using Terraform, AWS, and Kubernetes by processing YAML configuration files in a `.rabbit/` directory. It simplifies the process of setting up infrastructure across different environments with minimal setup. The action integrates seamlessly with GitHub workflows, enabling automatic planning and application or destruction based on actions like pushes, PRs, deletions, or manual triggers.
