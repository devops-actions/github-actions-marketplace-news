## Action Summary

This GitHub Action automates the building of Wails.io applications using GoLang and NodeJS. It supports various build platforms, obfuscation options, and uploads artifacts to GitHub or a release on tagged builds. The default configuration is set up to build for multiple platforms and upload results to GitHub. Users can customize the action by specifying different Go and Wails versions, build names, platforms, and uploading settings.
