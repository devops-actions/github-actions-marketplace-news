## Action Summary

SSG is a fast static site generator written in Go, which converts Markdown with YAML frontmatter into a complete website. It automates tasks such as building the site, serving it locally, and deploying it to various platforms like GitHub Pages, Netlify, Vercel, etc. The action provides features for generating sitemaps, feeds, search indexes, and SEO metadata, among others, making it suitable for creating blogs, portfolios, and other types of websites.
