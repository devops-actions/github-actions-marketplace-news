## Action Summary

Smyklot is a GitHub App that automates pull request approvals and merges by validating permissions against the `.github/CODEOWNERS` file. It supports multiple command formats, including slash commands, mentions, and bare commands, allowing users to approve or merge PRs with reactions or comments. The app handles command deduplication, provides emoji feedback, and can run as a GitHub Action or webhook service for all repositories installed on the App.
