## Action Summary

The SBOM Auditor Action audits Software Bill of Materials (SBOM) for license compliance by fetching, enriching, and auditing the licenses against predefined policies. It generates a detailed report with AI-assisted summaries if enabled, helping organizations ensure their software dependencies comply with licensing terms. The action supports multiple AI providers like OpenAI, Azure OpenAI, AWS Bedrock, and GitHub.
