## Action Summary

This GitHub Action automates uploading and publishing web game files to Wavedash. It simplifies the process of integrating Wavedash functionality into your project, handling both auto-creation of `wavedash.toml` and injection of the Wavedash SDK into HTML entrypoints. The action supports various configurations for game ID, upload directory, and entrypoint, as well as options to publish builds with release notes.
