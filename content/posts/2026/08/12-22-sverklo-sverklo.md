Sverklo is an open-source local-first Memory Control Plane (MCP) server designed to enhance coding agent productivity by providing context and insights into the codebase. It helps agents make informed decisions by offering symbols, callers, diffs, blast radius, and git-pinned decisions before editing. Sverklo supports multiple language models and integrates with popular coding tools like Claude Code, Cursor, Windsurf, Codex CLI, and any MCP-speaking agent.
