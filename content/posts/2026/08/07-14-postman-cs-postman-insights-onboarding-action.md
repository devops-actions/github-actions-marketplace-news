## Action Summary

This GitHub Action automates the process of linking services discovered by Postman Insights to API Catalog workspaces and git repositories after deployment. It helps ensure that all discovered services are included in the organization's catalog with detailed information such as a collection, repo link, and live telemetry. The action uses a human-user PMAK and session access token for authentication and validates these credentials before linking writes.
