## Action Summary

The `eslint-config-fk` action is an ESLint configuration for Försäkringskassan projects. It provides a custom base configuration tailored to FK's development guidelines, with rules set as warnings and disabled during local builds but enabled in CI/CD pipelines. The action simplifies the setup of ESLint configurations by providing pre-defined configurations for different project types such as Vue, TypeScript, and Cypress. It also supports overriding specific rules and global variables for certain files or directories.
