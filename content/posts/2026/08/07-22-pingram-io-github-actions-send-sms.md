## Action Summary

This GitHub Action sends SMS notifications using the Pingram API to notify on-call personnel, capture tracking IDs, and send media-only MMS. It supports sending SMS to individual or multiple recipients, scheduling sends, and logging tracking IDs for each notification. The action can be configured with various parameters such as API key, message content, recipient numbers, and more.
