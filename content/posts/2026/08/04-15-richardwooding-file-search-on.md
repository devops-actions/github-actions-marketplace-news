## Action Summary

This GitHub Action performs a file search on a directory tree using CEL expressions to filter files based on metadata and content-type-specific attributes. It supports 74 file formats across thirteen content-type families, including document, markup, data, plain text, images, audio, video, office, ebooks, and source code. The action is designed for use with Claude Code, allowing users to query files by their content types.
