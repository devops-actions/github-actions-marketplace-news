## Action Summary

This GitHub action automates the process of building Wails.io applications using GoLang and NodeJS. It installs necessary dependencies, builds the application, and optionally uploads the result to GitHub or a release on tagged builds. The default build includes both uploading workflow artifacts and publishing releases. Users can specify various configurations for different platforms, Go and Node.js versions, obfuscation settings, and more.
