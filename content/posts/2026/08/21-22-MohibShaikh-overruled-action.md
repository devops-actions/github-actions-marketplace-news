## Action Summary

This GitHub Action automates the auditing process of AI SOC agents using the overruled tool, which checks if an agent is overruled on ground-truth cases. It fails the workflow if the subject agent gets overruled and provides a JUnit XML report for further analysis. The action allows users to specify the investigation URL, token, number of runs, output format, and output file path.
