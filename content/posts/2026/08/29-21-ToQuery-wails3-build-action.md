## Action Summary

This GitHub Action automates the build process for Wails.io v3 projects. It installs GoLang and NodeJS, builds the application, and optionally uploads the results to GitHub or publishes them on a tagged release. The action supports various build options such as obfuscation, platform selection, caching, and package uploading.
