## Action Summary

This GitHub Action automates the deployment of a new container image to a Railway service in a shared project. It pins the Railway CLI release, resolves service and environment names to IDs, updates the service instance's image, triggers the deploy, waits for it to complete, and provides outputs for deployment ID, service ID, and environment ID. It supports specifying an optional environment name and handling different types of tokens.
