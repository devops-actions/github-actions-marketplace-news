## Action Summary

This GitHub Action allows users to run CI jobs on Debian-based virtual machines. It supports various Debian releases and architectures including x86_64, aarch64, riscv64, and ppc64le. The action is AI-ready and can generate CI workflows based on natural language descriptions, automating the selection of VMs, toolchains, and configurations for users. It supports pushing changes to source code and synchronizing it with the virtual machine.
