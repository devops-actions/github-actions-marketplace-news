## Action Summary

The Modern Pterodactyl Power GitHub Action sends power signals (`start`, `stop`, `restart`, or `kill`) to servers on a Pterodactyl panel, automating server management tasks. It targets the client API power endpoint and runs on Node.js 24 without additional dependencies. The action supports sending restart commands and provides outputs for the signal and state of the server after delivery.
