## Action Summary

The YAMLResume GitHub Action automates the creation of professional resumes from YAML files using the YAMLResume CLI. It builds multiple resumes in a single workflow step, supports custom build options such as skipping validation or PDF generation, and outputs generated file paths for use in subsequent steps. The action also works seamlessly with `actions/upload-artifact` to save generated files.
