## Action Summary

The GitHub Action "Code Review Board" automates the process of reviewing pull requests using multiple AI personas without relying on third-party software or storing sensitive information. It uses Anthropic's Claude API to generate independent reviews for each review persona, which are then combined into a single comment posted directly onto the PR. This tool helps prevent sycophancy in code reviews and provides a robust solution for maintaining high-quality code across multiple teams.
