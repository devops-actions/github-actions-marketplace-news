## Action Summary

This GitHub Action automates the validation, building, and publishing of Otzaria plugins to their store, ensuring that only valid updates are pushed to the main branch. It requires two secrets (OTZARIA_USER and OTZARIA_PASSWORD) in GitHub Actions settings. The action supports both automatic publication on push to the main branch and manual validation for pull requests, with customizable inputs such as app version, API reference URL, and build options.
