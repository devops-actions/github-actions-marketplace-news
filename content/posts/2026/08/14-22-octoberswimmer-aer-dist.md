## Action Summary

This GitHub Action automates the execution of Apex unit tests locally without using an org. It provides a local environment that mimics Salesforce's runtime by loading metadata, allowing developers to run tests and debug code in their own IDEs like VS Code or IntelliJ. The action supports various features such as SOQL queries, DML operations, governor limits, standard library methods, and testing framework functionalities.
