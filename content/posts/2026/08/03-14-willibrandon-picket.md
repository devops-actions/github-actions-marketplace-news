## Action Summary

This GitHub Action, Picket, provides a comprehensive secrets scanner for .NET projects that supports Git changes, Hugging Face models, GitLab resources, and integrates with CI/CD tools like GitHub Actions and Azure Pipelines. It offers a command-line interface for scanning files, repositories, and other sources, as well as support for embedding the scanner into applications using dotnet tool packages or AOT-safe libraries.
