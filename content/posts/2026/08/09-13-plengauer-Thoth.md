## Action Summary

This GitHub Action automates the collection and propagation of OpenTelemetry spans, metrics, and logs from shell scripts and GitHub workflows. It provides automatic context propagation via HTTP, auto-instrumentation of all commands, and supports installation via Debian or RPM packages, as well as distributable GitHub actions for workflow-level and job-level instrumentation.
