## Action Summary

This GitHub Action automates the upload and publication of web games to Wavedash. It allows developers to easily integrate game uploads into their CI/CD pipelines by leveraging a `wavedash.toml` configuration file or automatically creating one with the necessary settings. The action handles the creation of a build, publishing it to Wavedash with optional release notes, and caching the installed Wavedash CLI between runs for efficiency.
