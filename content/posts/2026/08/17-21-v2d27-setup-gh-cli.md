## Action Summary

This GitHub Action automates the installation of the GitHub CLI (`gh`) on self-hosted runners across multiple platforms and architectures. It supports multi-platform support, multi-architecture support, automatic archive format detection, tool caching, version flexibility, and platform detection. The action can be configured to install the latest version or a specific version of `gh`, and it simplifies setting up GitHub CLI in workflows by providing detailed usage examples and configuration options.
