## Action Summary

This action generates a HTML test coverage report based on the lcov coverage report generated by your test runner and comments it to a pull request. It does not run any tests but expects them to have been run by another action already. The key capabilities include generating a detailed coverage report, linking to specific files where coverage is lower, and displaying the total coverage percentage.
