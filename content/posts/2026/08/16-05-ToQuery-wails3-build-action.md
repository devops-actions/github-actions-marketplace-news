## Action Summary

This GitHub Action automates the building and packaging of Wails.io v3 projects. It installs GoLang and NodeJS, builds the application for different platforms, and optionally uploads the results to GitHub or releases on tagged builds. The action provides configuration options for customizing build settings, including Go version, Wails version, binary name, obfuscation, platform, caching, and package upload.
