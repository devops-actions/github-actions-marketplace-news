## Action Summary

Capsule is an isolated Git worktree and evidence tool that ensures reproducibility of code changes by verifying the execution of commands in a controlled environment without access to the original machine. It allows for testing and verification of patches independently of their source repository, providing both a reproduction check and a mechanism for creating verifiable receipts that can be used to verify the execution results.
